## Название

CryptoBook

## Статус

Приватное пространство для документов на Windows

## Краткое описание

CryptoBook — настольное приложение для работы с локальными документами и файлами. Редактируйте тексты, организуйте рабочее пространство, просматривайте медиафайлы и защищайте важные данные — всё на своём компьютере.

## Подробная информация

CryptoBook объединяет форматированный текстовый редактор, файловый менеджер, быстрый поиск, предпросмотр медиафайлов и защищённое паролем хранилище `.cbook`.

Основные возможности:

- редактирование TXT, Markdown, RTF, XAML и других текстовых форматов;
- закладки, изображения, ссылки и форматирование документов;
- файловый менеджер и полнотекстовый поиск по рабочему пространству;
- светлая, тёмная, системная и сепия-темы;
- защита отдельных файлов и каталогов;
- автоматическое восстановление несохранённого документа;
- обновления приложения через GitHub.

CryptoBook работает в Windows 10/11. Проект активно развивается; для важных данных всегда сохраняйте отдельные резервные копии.

Исходный код и релизы: https://github.com/RomanovCopy/CryptoBook
