# Asset audit artifacts

- `asset-manifest.json` is the factual inventory of all tracked images.
- `contact-sheet.png` is a visual index used to detect duplicates, unrelated
  styles and unexpected content.
- `ATTESTATION.md` is the developer evidence form; it is intentionally still a
  draft until completed by the copyright holder.

The manifest and contact sheet are generated by
`tools/compliance/new_asset_inventory.py`. Rights conclusions are maintained
in the root `ASSET_PROVENANCE.md` and must not be inferred from Git metadata.
