# Подробные свойства файла

В FileExplorer выберите один файл и откройте **Подробные свойства** из контекстного меню или нажмите **Alt+Enter** в списке файлов. Для каталога доступен пункт контекстного меню. Обычные свойства Windows остаются отдельным действием.

Первым показывается тип, обнаруженный по содержимому, а не по расширению или значку. Проверка читает заголовок файла и, для MZ, заголовок PE по указанному в нём смещению. Она отмечает EXE/DLL и ярлыки под расширением изображения, активные расширения, двойное расширение вида `photo.jpg.exe`, невидимые символы и символы изменения направления текста. В имени и пути управляющие символы показаны как `\uXXXX`.

Распознаются заголовки MZ/PE, LNK, PNG, JPEG, GIF, BMP, WebP, TIFF, ICO, PDF, ZIP, OLE, 7-Zip, RAR и скриптов с `#!`. ZIP и OLE обозначаются как контейнеры: проверка не утверждает, что содержимое архива или документа безопасно. SVG, HEIF/AVIF и прочие форматы без поддерживаемого детектора могут остаться неопределёнными; сведения обработчика Windows при наличии всё равно попадут в таблицу.

Отчёт собирает:

- Полное имя, путь, последнее расширение, размер, даты создания/изменения/доступа с местным временем и UTC, атрибуты и цель файловой ссылки.
- Выделенное место на диске, размер с учётом сжатия/разреженности, ID файла, число жёстких ссылок, серийный номер и свойства тома.
- Владельца, группу, SID, правила DACL с наследованием и дескриптор SDDL. Это сохранённые правила, а не вычисление эффективных разрешений пользователя. SACL не запрашивается: для него нужны дополнительные привилегии.
- Имена и размеры потоков `$DATA`. Для `Zone.Identifier` также показывается текст, включая сохранённые Windows сведения об источнике скачивания, если они есть. Текст ограничен 16 384 символами с явной отметкой усечения. Другие потоки не интерпретируются.
- Все непустые свойства, перечисленные доступным read-only хранилищем Windows Property System: EXIF, параметры медиа, сведения документа и другие данные установленных обработчиков. Показываются технические ключи; если доступное неформатированное значение отличается от отображаемого, оно добавляется отдельной строкой `.Raw`.
- Ресурс версии. Для PE — поля COFF/PE/CLR, секции, а для управляемых сборок — имя, версия и ссылки на сборки. Файл не загружается как исполняемый модуль.
- Проверку встроенной Authenticode-подписи, поиск локальных каталожных подписей по SHA-256/SHA-1, проверку соответствия файла найденному каталогу, коды WinVerifyTrust и сведения сертификатов. Проверка выполняется без сетевого обновления списков отзыва; отсутствие каталога в локальной базе не доказывает отсутствие внешней подписи. Сведения сертификата показываются отдельно от результата проверки доверия.
- SHA-256 и SHA-512 по кнопке **Рассчитать хеши**. Обе суммы вычисляются за один проход с прогрессом и отменой. Активная запись в файл препятствует расчёту; изменение размера/времени во время чтения считается ошибкой.

Поиск работает по разделам, названиям, значениям и техническим ключам. Можно копировать выбранные строки или весь отчёт; фильтр не сокращает полный отчёт. Чтение идёт в фоне. Отмена проверяется между операциями; уже выполняющийся нативный вызов Windows может завершиться позже. Недоступные разделы отмечаются ошибкой, остальные сведения сохраняются.

Для MTP и других нелокальных источников показываются доступные сведения выбранного объекта. Проверка содержимого, Windows/NTFS-метаданные, подписи и хеши требуют локальной копии. Зашифрованный `.cbook` рассматривается как файл-контейнер, без автоматической расшифровки содержимого.

Совпадение заголовка с форматом изображения и действительная подпись не гарантируют безвредность файла. Это просмотр свойств и признаков маскировки, не антивирус и не запрет запуска. Полного универсального набора всех внутренних данных для любого формата не существует; охват зависит от формата, обработчиков, файловой системы и прав доступа.

Справочные контракты Windows: [PE](https://learn.microsoft.com/en-us/windows/win32/debug/pe-format), [Property System](https://learn.microsoft.com/en-us/windows/win32/api/propsys/ne-propsys-getpropertystoreflags), [WinVerifyTrust](https://learn.microsoft.com/en-us/windows/win32/api/wintrust/ns-wintrust-wintrust_data), [потоки файлов](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-findfirststreamw).
