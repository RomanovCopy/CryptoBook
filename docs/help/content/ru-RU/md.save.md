# Сохранение исходника Markdown

Сохраняется исходный текст, включая разметку, а не видимая копия предпросмотра. Сначала выберите Markdown-редактор, особенно если обычный документ также открыт.

## Порядок действий

1. Нажмите **Сохранить** или Ctrl+S для записи текущего файла.
2. **Сохранить как** или Ctrl+Shift+S сохраняет в другом месте. При отмене выбора исходник остаётся открыт с изменениями.
3. Повторно откройте копию: проверьте текст, разметку и относительные изображения. Изображения не встраиваются в .md; переносите их отдельно с сохранением относительных путей.

## Проверка, отмена и ограничения

При открытии распознаются UTF-8/16/32 с BOM; без BOM ожидается UTF-8. Сохранение открытого Markdown сохраняет его распознанную кодировку, BOM и исходные переводы строк; новый Markdown создаётся UTF-8 без BOM. Произвольного переключателя кодировки нет. Защищённый Markdown также сохраняет исходник; условия защиты описаны отдельно. Экспорт обычного оформленного документа обратно в Markdown не поддерживается. При ошибке записи сохраните по другому пути и не закрывайте несохранённый текст.
