# Фон и кадрирование страницы

Фон занимает бумагу за текстом. В отличие от обычной вставки, его можно двигать внутри кадра страницы. До окончательного сохранения сохраните исходное изображение отдельно.

## Порядок действий

1. В панели **Шрифт**, в области **Бумага**, нажмите **Выбрать фоновое изображение документа. Перемещение на странице: Ctrl + левая кнопка мыши.** и выберите файл.
2. Удерживая Ctrl, перетаскивайте фон левой кнопкой мыши. Esc отменяет текущее перетаскивание. **Удалить фоновое изображение документа** убирает фон.
3. Сохраните как XamlPackage. При первом сохранении редактируемого фона прочитайте предупреждение о фиксации кадрирования. Отмена оставляет файл и фон без окончательной фиксации.

## Проверка, отмена и ограничения

После успешной записи сохраняется только видимая область: скрытые края изображения отбрасываются, дальнейшее перемещение этого кадра блокируется. Для другого кадрирования заново выберите исходное изображение. Ошибка или отмена записи не должны считаться сохранением. Ctrl+Z может отменять редактирование, но не возвращает отброшенные пиксели из уже записанного файла. RTF/TXT/XAML не подходят для сохранения такого фона; проверяйте повторное открытие XamlPackage.
