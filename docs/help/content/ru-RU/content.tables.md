# Редактирование существующей таблицы

Таблицу можно редактировать в обычном документе: например, после вставки оформленного ответа AI или открытия XamlPackage с таблицей. Отдельной команды создания пустой таблицы нет.

## Порядок действий

1. Поставьте каретку внутри одной ячейки. Для изменения текста просто вводите его; не выделяйте несколько ячеек для структурной операции.
2. В контекстном меню **Таблица** выберите добавление строки выше/ниже или столбца слева/справа.
3. Удаление строки или столбца удаляет их содержимое. Удаление последней строки/последнего столбца убирает всю таблицу: заранее сохраните копию и используйте Ctrl+Z при ошибке.

![Редактирование существующей таблицы — Состояние интерфейса 1.](images/S14-a.png "Редактирование существующей таблицы — Состояние интерфейса 1.")

## Проверка, отмена и ограничения

Команды структуры работают только с прямоугольной таблицей без объединений, при каретке или выделении внутри одной ячейки и в редактировании. Вне ячейки, при объединениях или выделении нескольких ячеек команды недоступны. Вернитесь в одну подходящую ячейку. Проверьте количество строк/столбцов, отмену и повторное открытие XamlPackage. Формулы и вычисления не предоставляются; Markdown-таблица меняется в исходном тексте.
