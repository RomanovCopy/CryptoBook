# Абзацы, интервалы и списки

Параметры абзаца действуют на абзацы выделенного текста или на абзац с кареткой. Откройте обычный документ, затем панель **Абзац**.

## Порядок действий

1. Выберите выравнивание: **По левому краю**, **По центру**, **По правому краю** или **По ширине**.
2. **Отступ первой строки** задаёт отступ первой строки; кнопки **Увеличить межстрочный интервал** и **Уменьшить межстрочный интервал** меняют межстрочный интервал по шагам.
3. В панели **Списки** выберите маркированный или нумерованный список. Команда очистки списка возвращает обычные абзацы.

## Проверка, отмена и ограничения

Проверьте несколько строк и соседние абзацы: выравнивание не ограничивается отдельным словом. Enter переносит строку без нового абзаца; Ctrl+Enter создаёт абзац или следующий пункт списка. Ctrl+Z отменяет изменение. Если оформление теряется после открытия, используйте RTF/XamlPackage вместо TXT/XAML. В Markdown списки задаются исходной разметкой.
