# Горячие клавиши и область фокуса

Сочетание действует в указанном окне или элементе, когда соответствующая команда доступна. Сначала щёлкните нужный редактор, поле или список. Вне редактора Tab и Shift+Tab перемещают фокус; внутри редактора Tab может вставлять табуляцию. На флажке или кнопке действует Space, а Enter учитывает правила текущего поля.

## Документы и защита

| Клавиши | Область и действие |
| --- | --- |
| Ctrl+S / Ctrl+Shift+S | Обычный или Markdown-редактор: сохранить / сохранить как |
| Ctrl+Z / Ctrl+Y | Редактируемый текст в фокусе: отменить / повторить доступное изменение |
| Ctrl+X / C / V / A | Текстовое поле в фокусе: вырезать / копировать / вставить / выделить всё |
| Ctrl+B / I / U | Обычный редактор: полужирный / курсив / подчёркнутый; не команда оформления Markdown-исходника |
| Enter / Ctrl+Enter | Обычный редактор: разрыв строки / новый абзац; списки сохраняют свои правила |
| ↑; ←/→; Enter; Esc | При появлении системных подсказок слов Windows: перейти к подсказкам; выбрать слово; вставить выбранное; закрыть без вставки |
| Ctrl+F | Обычный или Markdown-документ: открыть поиск |
| F3 / Shift+F3 | При открытом поиске документа: следующее / предыдущее совпадение |
| Enter / Shift+Enter | Поле поиска документа: следующее / предыдущее совпадение |
| Esc | Открытый поиск документа: закрыть |
| Ctrl+L | Главное окно или настройки: сбросить установленный ключ; учитывайте снимок защищённой работы |
| Ctrl+колесо | Обычный редактор: масштаб; кнопка 100% возвращает исходный |
| Ctrl+ЛКМ и перетаскивание / Esc | Фон документа: переместить / отменить текущий сдвиг |
| Alt+↑ / Alt+↓ | Выбранная встроенная картинка: переместить; в дереве структуры — переместить узел |
| Delete / Esc | Выбранная встроенная картинка: удалить / снять выбор |
| Ctrl+Enter | Дерево структуры: добавить абзац к выбранному узлу |
| ← / PageUp; → / PageDown; Home / End | Предпросмотр обычного документа: предыдущая / следующая / первая / последняя страница |

## Другие окна

| Клавиши | Область и действие |
| --- | --- |
| Ctrl+Enter | Поле вопроса AI: отправить; обычный Enter переносит строку |
| Ctrl+M | Файловый менеджер: групповое переименование при выборе не менее двух подходящих файлов |
| Alt+Enter | Список файлов: подробные свойства выбранного элемента |
| Enter / Esc | Поле адреса: применить / отменить; при редактировании имени — подтвердить / отменить имя |
| Enter | Поле поиска по имени в настройках: запустить поиск; окно ключа — подтвердить при выполнении требований |
| Esc | Групповое переименование: закрыть либо запросить отмену выполняемой операции |
| ← / →; ↑ / ↓; Delete | Просмотр изображений: соседний файл; увеличить / уменьшить; отправить файл в корзину после подтверждения |
| ← / →; Alt+← / Alt+→ | Видео: перемотать; предыдущее / следующее видео |
| F1 | Главное окно: открыть/активировать справку; сама справка: активировать её |
| Ctrl+F; Alt+← / Alt+→ | Справка: фокус поиска; назад / вперёд по истории |
| Enter | Поиск справки: открыть выбранный результат; кнопка иллюстрации в фокусе: увеличить |
| Esc | Справка: закрыть увеличенное изображение; в поле поиска очистить запрос, затем вернуть фокус статье |
| Alt+F4 | Закрыть активное окно с его обычной проверкой несохранённой работы |

Ctrl при перетаскивании файлов выбирает копирование; обычное перетаскивание — перемещение. Это жест файлового менеджера. Ctrl+N/O/P и Delete/F2 для файлов не назначены приложением как универсальные команды: пользуйтесь видимым меню. Ctrl+C в текстовом поле AI не заменяет отдельную кнопку копирования выбранных сообщений. Ограничения Undo для картинок описаны в теме редактирования.
