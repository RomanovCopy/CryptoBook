# Форматы и кодировки

Формат определяет, что останется после сохранения и повторного открытия. Для текста без оформления подходит TXT; для оформленного документа выбирайте RTF или XamlPackage. Проверяйте результат на копии перед преобразованием важного файла.

## Что сохраняется

| Формат | Поведение в CryptoBook |
| --- | --- |
| RTF (`.rtf`) | Оформленный текст; поддерживаются встроенные изображения. Совместимость сложной вёрстки с другими редакторами проверяйте отдельно |
| XamlPackage (`.XamlPackage`) | Оформленный документ с встроенными ресурсами; подходит для содержимого CryptoBook, включая фон страницы |
| TXT и другие обычные текстовые типы | Текст без шрифтов, цветов, изображений и структуры таблиц |
| XAML (`.xaml`) | В текущем приложении открывается и сохраняется как обычный текст; это не замена XamlPackage |
| Markdown (`.md`, `.markdown`) | Исходный текст разметки в отдельном редакторе; предпросмотр строится из него |
| Защищённый документ (`.cbook`) | Контейнер CryptoBook, для чтения и записи которого нужен подходящий ключ |

При текстовом экспорте слова из таблицы могут остаться, но сама таблица и изображения не сохраняются. Смена расширения в файловом менеджере не преобразует данные. Не рассчитывайте на обязательное предупреждение о потере оформления.

## Как выбрать формат

1. Откройте **Файл → Сохранить как**.
2. Выберите тип и соответствующее расширение. Для Markdown предлагаются его исходный формат и текстовый файл; обычный документ нельзя обратным преобразованием сохранить в Markdown.
3. Сохраните под новым именем. Закройте копию, откройте снова и сравните текст, оформление и изображения с оригиналом.

## Кодировки

Отдельного выбора произвольной кодировки в интерфейсе нет. Обычный текстовый экспорт записывает UTF-8 без BOM. RTF и XamlPackage используют собственное представление; это не простой текст UTF-8.

Новый Markdown создаётся в UTF-8 без BOM. Для открытого Markdown сохраняются распознанные UTF-8, UTF-16 или UTF-32 с их BOM и имеющиеся переводы строк. Без BOM ожидается UTF-8; старые однобайтовые кодировки автоматически не подбираются. Если байты не соответствуют распознанной кодировке, возможно появление заменённых символов и переход к UTF-8 при следующем сохранении. Не перезаписывайте оригинал с нечитаемым текстом: отмените работу с ним и подготовьте правильно перекодированную копию во внешнем редакторе.

## Проверка результата и возврат

Проверьте кириллицу, украинские буквы, умляуты, переносы строк и существенное оформление после повторного открытия. Отмена диалога не меняет текущий формат. После успешного **Сохранить как** для возврата к оригиналу откройте старый файл: следующие сохранения уже направлены в копию.

PDF и медиа не являются форматами сохранения обычного документа в этом диалоге. Их просмотр описывается отдельно. Защита файла не исправляет потери, уже внесённые текстовым экспортом.
