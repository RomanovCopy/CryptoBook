# Основные операции с текстом

Выделите фрагмент, чтобы заменить, скопировать или удалить его. Команды работают в обычном редакторе; сначала щёлкните по тексту документа.

## Порядок действий

1. Выделите текст мышью или Shift со стрелками. Ctrl+A выделяет весь документ.
2. Откройте контекстное меню: **Копировать** (Ctrl+C), **Вырезать** (Ctrl+X), **Вставить** (Ctrl+V). Вставка заменяет выделенный фрагмент.
3. Для исправления используйте **Отменить** (Ctrl+Z) и **Повторить** (Ctrl+Y). Enter переносит строку внутри текущего абзаца; Ctrl+Enter создаёт новый абзац.

## Подсказки слов Windows

Во время набора Windows может показывать варианты слов над курсором. Выбрать подходящее слово можно без мыши:

1. Когда появятся подсказки, нажмите **↑**, чтобы перейти к ним.
2. Клавишами **←/→** выберите нужное слово.
3. Нажмите **Enter**, чтобы вставить выбранный вариант.

**Esc** закрывает подсказки без вставки. Enter подтверждает слово, когда вы перешли к выбору подсказки; при обычном вводе он сохраняет действие переноса строки.

Это системная функция Windows. Чтобы включить её, откройте **Параметры → Время и язык → Ввод** в Windows 11 или **Параметры → Устройства → Ввод** в Windows 10. Включите показ текстовых предложений при вводе с физической клавиатуры. Доступность вариантов зависит от настроек Windows и языка ввода.

## Проверка, отмена и ограничения

**Очистить документ** удаляет всё содержимое текущего документа; сначала сохраните нужную копию. **Удалить пустые абзацы** убирает пустые абзацы, поэтому промежутки могут исчезнуть. Проверьте текст и отмените неудачное изменение до продолжения работы. История отмены не заменяет резервную копию файла. Если команда недоступна, проверьте выделение, фокус и режим редактирования.
