# Tastenkürzel und Fokus

Ein Kürzel wirkt im genannten Fenster oder Steuerelement, wenn sein Befehl verfügbar ist. Klicken Sie zuerst in den gewünschten Editor, das Feld oder die Liste. Außerhalb eines Editors bewegen Tab und Shift+Tab den Fokus; im Editor kann Tab ein Tabulatorzeichen einfügen. Space wirkt auf ein fokussiertes Kontrollkästchen oder eine Schaltfläche; Enter folgt den Regeln des aktuellen Feldes.

Die Tabellen verwenden internationale Tastennamen. Auf einer deutschen Tastatur entsprechen Ctrl der Strg-Taste, Shift der Umschalttaste, Enter der Eingabetaste, Space der Leertaste und Delete der Entf-Taste. PageUp/PageDown heißen Bild auf/Bild ab; Home/End entsprechen Pos1/Ende.

## Dokumente und Schutz

| Tasten | Bereich und Aktion |
| --- | --- |
| Ctrl+S / Ctrl+Shift+S | Gewöhnlicher oder Markdown-Editor: speichern / speichern unter |
| Ctrl+Z / Ctrl+Y | Bearbeitbarer Text im Fokus: verfügbare Änderung rückgängig machen / wiederholen |
| Ctrl+X / C / V / A | Textfeld im Fokus: ausschneiden / kopieren / einfügen / alles auswählen |
| Ctrl+B / I / U | Gewöhnlicher Editor: fett / kursiv / unterstrichen; keine Markdown-Quelltextformatierung |
| Enter / Ctrl+Enter | Gewöhnlicher Editor: Zeilenumbruch / neuer Absatz; Listen behalten eigene Regeln |
| Ctrl+F | Gewöhnliches oder Markdown-Dokument: Suche öffnen |
| F3 / Shift+F3 | Bei geöffneter Dokumentsuche: nächster / vorheriger Treffer |
| Enter / Shift+Enter | Suchfeld im Dokument: nächster / vorheriger Treffer |
| Esc | Geöffnete Dokumentsuche: schließen |
| Ctrl+L | Hauptfenster oder Einstellungen: gesetzten Schlüssel zurücksetzen; Schnappschuss geschützter Arbeit beachten |
| Ctrl+Mausrad | Gewöhnlicher Editor: Zoom; die Schaltfläche 100% setzt ihn zurück |
| Ctrl+Ziehen mit linker Maustaste / Esc | Dokumenthintergrund: verschieben / aktuelle Verschiebung abbrechen |
| Alt+↑ / Alt+↓ | Ausgewähltes eingebettetes Bild: verschieben; Strukturbaum: Knoten verschieben |
| Delete / Esc | Ausgewähltes eingebettetes Bild: löschen / Auswahl aufheben |
| Ctrl+Enter | Strukturbaum: Absatz am ausgewählten Knoten hinzufügen |
| ← / PageUp; → / PageDown; Home / End | Vorschau eines gewöhnlichen Dokuments: vorherige / nächste / erste / letzte Seite |

## Andere Fenster

| Tasten | Bereich und Aktion |
| --- | --- |
| Ctrl+Enter | KI-Fragefeld: senden; normales Enter fügt einen Zeilenumbruch ein |
| Ctrl+M | Dateimanager: Mehrfachumbenennung mit mindestens zwei geeigneten ausgewählten Dateien |
| Alt+Enter | Dateiliste: detaillierte Eigenschaften des gewählten Elements |
| Enter / Esc | Adressfeld: anwenden / abbrechen; beim Bearbeiten eines Namens: Namen bestätigen / verwerfen |
| Enter | Dateinamensuche in Einstellungen: suchen; Schlüsseldialog: bei erfüllten Anforderungen bestätigen |
| Esc | Mehrfachumbenennung: schließen oder Abbruch des laufenden Vorgangs anfordern |
| ← / →; ↑ / ↓; Delete | Bildbetrachter: Nachbardatei; vergrößern / verkleinern; Datei nach Bestätigung in den Papierkorb verschieben |
| ← / →; Alt+← / Alt+→ | Video: spulen; vorheriges / nächstes Video |
| F1 | Hauptfenster: Hilfe öffnen/aktivieren; Hilfe selbst: aktivieren |
| Ctrl+F; Alt+← / Alt+→ | Hilfe: Suchfokus; zurück / vorwärts im Verlauf |
| Enter | Hilfesuche: gewählten Treffer öffnen; fokussierte Bildschaltfläche: vergrößern |
| Esc | Hilfe: vergrößertes Bild schließen; Suchfeld: Anfrage leeren, danach Fokus zum Artikel |
| Alt+F4 | Aktives Fenster mit seinen üblichen Prüfungen ungespeicherter Arbeit schließen |

Ctrl beim Ziehen von Dateien wählt Kopieren, gewöhnliches Ziehen Verschieben. Dies ist eine Dateimanager-Geste. Ctrl+N/O/P und Delete/F2 für Dateien sind nicht als allgemeine Anwendungsbefehle zugewiesen: Verwenden Sie das sichtbare Menü. Ctrl+C in einem KI-Textfeld ersetzt nicht die separate Schaltfläche zum Kopieren ausgewählter Nachrichten. Einschränkungen beim Rückgängigmachen von Bildänderungen stehen im Bearbeitungsthema.
