# Schrift, Textfarbe und Hervorhebung

**Schriftart** ändert die markierte Schrift. Ohne Auswahl gelten Einstellungen für die anschließende Eingabe. Öffnen Sie ein normales Dokument im Bearbeitungsmodus.

## Schritte

1. Markieren Sie Text und öffnen Sie **Schriftart** über dem Dokument.
2. Wählen Sie **Schriftfamilie**, **Stil**, **Schriftstärke**, **Verzierung**, **Schriftbreite** und **Größe**.
3. **Farbe** bestimmt die Buchstabenfarbe, **Hervorhebung** deren Hintergrund. Die Papierfarbe ist getrennt. **Formatierung _löschen** im Kontextmenü setzt Textformatierung zurück.

![Schrift, Textfarbe und Hervorhebung — Oberflächenzustand 1.](images/S08-b.png "Schrift, Textfarbe und Hervorhebung — Oberflächenzustand 1.")

## Prüfung, Rückgängigmachen und Grenzen

Prüfen Sie die Auswahl; Strg+Z macht eine Änderung rückgängig. Verfügbare Familien und Schnitte hängen von installierten Schriften ab. Speichern Sie als RTF oder XamlPackage und öffnen Sie eine Kopie zur Kontrolle. TXT und der aktuelle XAML-Handler speichern Text ohne diese Formatierung. Markdown verwendet seine eigene Auszeichnung.
