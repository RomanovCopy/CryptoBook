# Die Tintenpalette

**Tintenpalette** über dem Dokument bietet schnelle Textfarben. Das Ändern eines Farbfelds und das Anwenden auf Text sind getrennte Vorgänge.

## Schritte

1. Markieren Sie Text oder setzen Sie die Einfügemarke für neue Eingaben.
2. Klicken Sie eine Palettenfarbe an, um sie auf den Text anzuwenden.
3. Zum Ersetzen eines Felds klicken Sie es mit der rechten Maustaste an und wählen eine Farbe. Klicken Sie das Feld anschließend normal an, wenn Sie die neue Farbe anwenden möchten.

![Die Tintenpalette — Oberflächenzustand 1.](images/S09-c.png "Die Tintenpalette — Oberflächenzustand 1.")

## Prüfung, Rückgängigmachen und Grenzen

Prüfen Sie Buchstaben und Feldhinweis. Die Auswahl im Farbsatz ändert die Palette, ohne das Dokument automatisch umzufärben. Ein Klick außerhalb schließt den Farbsatz. Strg+Z betrifft Dokumentänderungen; die frühere Feldfarbe wählen Sie manuell wieder aus. Die Palette wird in den Programmeinstellungen gespeichert und ändert das Fensterdesign nicht. TXT kann Textfarben nicht erhalten.
