# Markdown-Quelltext bearbeiten

Markdown ist ein eigenes Textdokument mit Auszeichnung. Es kann neben einem normalen Dokument geöffnet bleiben; Dateibefehle gelten für den ausgewählten Editor.

## Schritte

1. Öffnen Sie eine .md-Datei oder erstellen Sie ein Markdown-Dokument. Geben Sie Auszeichnung im Quelltextfeld ein. Tab fügt einen Tabulator ein; Strg+Z macht Eingaben in diesem Feld rückgängig.
2. **Vorschau** zeigt das Ergebnis; **Editor** führt zum Quelltext zurück. Ändern Sie die Auszeichnung, um das Ergebnis zu ändern.
3. Die Hilfeschaltfläche öffnet den Syntaxartikel in einem separaten nichtmodalen Fenster. Haupteditor und beide Dokumente bleiben erhalten. Schließen Sie Hilfe über die Fensterschaltfläche oder Alt+F4, wenn sie den Fokus hat.

![Markdown-Quelltext bearbeiten — Oberflächenzustand 1.](images/S17-a.png "Markdown-Quelltext bearbeiten — Oberflächenzustand 1.")

## Prüfung, Rückgängigmachen und Grenzen

Speichern Sie mit **Speichern** oder Strg+S; Strg+Umschalt+S wählt eine andere Datei. Prüfen Sie den Quelltext nach erneutem Öffnen. Die Vorschau wird aus dem aktuellen Text neu erstellt und nicht zurück in Markdown umgewandelt. Formatierungsleisten des normalen Editors formatieren Markdown nicht. Ein Seitenwechsel speichert keine Änderungen; beachten Sie ungespeicherten Text vor dem Schließen.
