# Шрифт, колір і виділення

Панель **Шрифт** змінює оформлення виділеного тексту. Без виділення параметри застосовуються до подальшого введення. Відкрийте звичайний документ у режимі редагування.

## Порядок дій

1. Виділіть фрагмент і розгорніть **Шрифт** над документом.
2. Виберіть **Сімейство шрифтів**, **Стиль**, **Накреслення**, **Оформлення**, **Ширина** та **Розмір**.
3. **Колір** задає колір літер, **Виділення** — тло виділення. Колір паперу змінюється окремо. Щоб скинути оформлення тексту, скористайтеся **_Очистити форматування** у контекстному меню.

![Шрифт, колір і виділення — Стан інтерфейсу 1.](images/S08-b.png "Шрифт, колір і виділення — Стан інтерфейсу 1.")

## Перевірка, скасування та обмеження

Перевірте вигляд вибраного фрагмента; Ctrl+Z скасовує зміну. Доступні родини й накреслення залежать від установлених шрифтів. Для збереження оформлення використовуйте RTF або XamlPackage та повторно відкрийте копію. TXT і поточний обробник XAML зберігають текст без цього оформлення. Markdown використовує власну розмітку.
