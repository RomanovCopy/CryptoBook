# Основні операції з текстом

Виділіть фрагмент, щоб замінити, скопіювати або видалити його. Команди працюють у звичайному редакторі; спочатку клацніть текст документа.

## Порядок дій

1. Виділіть текст мишею або Shift зі стрілками. Ctrl+A виділяє весь документ.
2. Відкрийте контекстне меню: **Копіювати** (Ctrl+C), **Вирізати** (Ctrl+X), **Вставити** (Ctrl+V). Вставлення замінює виділений фрагмент.
3. Скористайтеся **Скасувати** (Ctrl+Z) і **Повторити** (Ctrl+Y). Enter переносить рядок усередині поточного абзацу; Ctrl+Enter створює новий абзац.

## Текстові пропозиції Windows

Під час введення Windows може показувати варіанти слів над курсором. Вибрати потрібне слово можна без миші:

1. Коли з’являться пропозиції, натисніть **↑**, щоб перейти до них.
2. Клавішами **←/→** виберіть потрібне слово.
3. Натисніть **Enter**, щоб вставити вибраний варіант.

**Esc** закриває пропозиції без вставлення слова. Enter підтверджує слово, коли ви перейшли до вибору пропозиції; під час звичайного введення він зберігає дію перенесення рядка.

Це системна функція Windows. Щоб увімкнути її, відкрийте **Налаштування → Час і мова → Введення** у Windows 11 або **Налаштування → Пристрої → Введення** у Windows 10. Увімкніть текстові пропозиції для фізичної клавіатури. Доступність варіантів залежить від налаштувань Windows і мови введення.

## Перевірка, скасування та обмеження

**Очистити документ** видаляє весь вміст поточного документа: спочатку збережіть копію. **Видалити порожні абзаци** прибирає порожні абзаци, тому проміжки можуть зникнути. Перевірте текст і скасуйте небажану зміну до продовження роботи. Історія скасування не замінює резервної копії файла. Якщо команда недоступна, перевірте виділення, фокус і режим редагування.
