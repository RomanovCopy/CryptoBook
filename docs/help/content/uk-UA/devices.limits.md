# Можливості й обмеження пристроїв

Команди залежать від джерела, об’єкта та його прав. Android є додатковим сховищем файлів, але не надає всіх можливостей локального Windows-диска.

## Перед початком

> Видалення на Android незворотне з погляду CryptoBook. Відновлення локальних операцій і кошик Windows не повертають видалені об’єкти пристрою. Розшифрований результат зберігається без захисту.

| Дія | Локальна папка | Android/MTP |
| --- | --- | --- |
| Навігація, копіювання, переміщення, створення папок, перейменування | За правами папки | За правами пристрою та об’єкта |
| Видалення у файловому менеджері | Кошик Windows із підтвердженням | Постійне з підтвердженням |
| Пошук робочої папки, моніторинг, групове перейменування | За власними умовами | Не підтримуються як локальні команди |
| Зовнішнє відкриття, повні властивості та хеші | За власними умовами | Спершу локальна копія |
| Короткий перегляд тексту/зображень | Підтримувані файли | Через потік без автоматичного розшифрування |

## Порядок дій

1. Для повного перегляду чи докладних властивостей скопіюйте файл пристрою в локальну папку й працюйте з копією.
2. Для розшифрування на самому пристрої введіть відповідний ключ, виберіть один читабельний захищений файл і **Розшифрувати вибрані елементи**.
3. У вікні **Розшифрування документа** виберіть доступний формат і **Замінити захищений оригінал розшифрованим файлом** для результату на пристрої. Потрібні права запису й видалення; перевірте попередження перед підтвердженням.
4. Щоб залишити захищений оригінал, виберіть розшифровану копію та явно перевірте її призначення.

## Перевірка результату

Після успішної заміни результат знаходиться в папці пристрою. Його назва й розширення можуть відрізнятися. Розшифрування читабельного віддаленого файла не потребує окремого дозволу на шифрування.

## Скасування й повернення

До підтвердження закрийте параметри. Після запису не розраховуйте на універсальне скасування; зберігайте окрему захищену копію за потреби.

## Якщо не вдалося

Недоступна команда зазвичай означає невідповідний об’єкт, відсутній ключ або права. Записувані файли Android можуть дозволяти шифрування/захищені копії за своїми правами, але це не означає рекурсивного шифрування віддаленої папки. Повний цикл захисту описується окремо.
