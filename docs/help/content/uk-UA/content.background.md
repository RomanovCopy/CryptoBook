# Тло та кадрування сторінки

Тло заповнює папір позаду тексту. На відміну від звичайної вставки, його можна рухати в межах кадру сторінки. Перед остаточним збереженням залиште оригінал зображення окремо.

## Порядок дій

1. У **Шрифт**, в області **Папір**, натисніть **Вибрати фонове зображення документа. Переміщення на сторінці: Ctrl + ліва кнопка миші.** та виберіть файл.
2. Утримуйте Ctrl і перетягуйте тло лівою кнопкою миші. Esc скасовує поточне перетягування. **Видалити фонове зображення документа** прибирає тло.
3. Збережіть як XamlPackage. Під час першого збереження рухомого тла прочитайте попередження про фіксацію кадрування. Скасування залишає файл і тло без остаточної фіксації.

## Перевірка, скасування та обмеження

Після успішного запису зберігається лише видима область: приховані краї відкидаються, переміщення цього кадру блокується. Для іншого кадрування знову виберіть оригінал. Помилка чи скасування запису не є успішним збереженням. Ctrl+Z може скасовувати редагування, але не повертає відкинуті пікселі з уже записаного файла. RTF/TXT/XAML не підходять для такого тла; перевіряйте повторне відкриття XamlPackage.
