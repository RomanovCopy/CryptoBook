# Збереження вихідного Markdown

Зберігається вихідний текст разом із розміткою, а не видима копія перегляду. Спочатку виберіть Markdown-редактор, особливо якщо відкрито також звичайний документ.

## Порядок дій

1. Натисніть **Зберегти** або Ctrl+S для запису поточного файла.
2. **Зберегти як** або Ctrl+Shift+S зберігає в іншому місці. Скасування вибору залишає текст відкритим зі змінами.
3. Відкрийте копію й перевірте текст, розмітку та відносні зображення. Зображення не вбудовуються в .md: переносьте їх окремо зі збереженням відносних шляхів.

## Перевірка, скасування та обмеження

Під час відкриття розпізнаються UTF-8/16/32 із BOM; без BOM очікується UTF-8. Збереження залишає розпізнане кодування, BOM і вихідні переводи рядків. Новий Markdown створюється як UTF-8 без BOM; довільного вибору кодування немає. Захищений Markdown теж зберігає вихідний текст; умови захисту описано окремо. Експорт звичайного оформленого документа в Markdown не підтримується. У разі помилки запису збережіть в іншому місці й не закривайте незбережений текст.
