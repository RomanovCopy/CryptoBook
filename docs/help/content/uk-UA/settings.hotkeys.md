# Гарячі клавіші та область фокуса

Сполучення діє у вказаному вікні або елементі, коли команда доступна. Спочатку клацніть потрібний редактор, поле чи список. Поза редактором Tab і Shift+Tab переміщують фокус; у редакторі Tab може вставляти табуляцію. Space діє на прапорці чи кнопці у фокусі, а Enter враховує правила поточного поля.

## Документи та захист

| Клавіші | Область і дія |
| --- | --- |
| Ctrl+S / Ctrl+Shift+S | Звичайний або Markdown-редактор: зберегти / зберегти як |
| Ctrl+Z / Ctrl+Y | Редагований текст у фокусі: скасувати / повторити доступну зміну |
| Ctrl+X / C / V / A | Текстове поле у фокусі: вирізати / копіювати / вставити / вибрати все |
| Ctrl+B / I / U | Звичайний редактор: напівжирний / курсив / підкреслений; не оформлення Markdown-джерела |
| Enter / Ctrl+Enter | Звичайний редактор: розрив рядка / новий абзац; списки зберігають власні правила |
| ↑; ←/→; Enter; Esc | Коли з’являються текстові пропозиції Windows: перейти до пропозицій; вибрати слово; вставити вибране; закрити без вставлення |
| Ctrl+F | Звичайний або Markdown-документ: відкрити пошук |
| F3 / Shift+F3 | За відкритого пошуку документа: наступний / попередній збіг |
| Enter / Shift+Enter | Поле пошуку документа: наступний / попередній збіг |
| Esc | Відкритий пошук документа: закрити |
| Ctrl+L | Головне вікно чи налаштування: скинути встановлений ключ; врахуйте знімок захищеної роботи |
| Ctrl+колесо | Звичайний редактор: масштаб; кнопка 100% повертає початковий |
| Ctrl+ЛКМ із перетягуванням / Esc | Фон документа: перемістити / скасувати поточний зсув |
| Alt+↑ / Alt+↓ | Вибране вбудоване зображення: перемістити; у дереві структури — перемістити вузол |
| Delete / Esc | Вибране вбудоване зображення: видалити / скасувати вибір |
| Ctrl+Enter | Дерево структури: додати абзац до вибраного вузла |
| ← / PageUp; → / PageDown; Home / End | Попередній перегляд звичайного документа: попередня / наступна / перша / остання сторінка |

## Інші вікна

| Клавіші | Область і дія |
| --- | --- |
| Ctrl+Enter | Поле запиту AI: надіслати; звичайний Enter переносить рядок |
| Ctrl+M | Файловий менеджер: групове перейменування за вибору щонайменше двох придатних файлів |
| Alt+Enter | Список файлів: докладні властивості вибраного елемента |
| Enter / Esc | Поле адреси: застосувати / скасувати; під час редагування імені — підтвердити / скасувати ім'я |
| Enter | Пошук за іменем у налаштуваннях: запустити пошук; вікно ключа: підтвердити за виконання вимог |
| Esc | Групове перейменування: закрити або запросити скасування поточної операції |
| ← / →; ↑ / ↓; Delete | Перегляд зображень: сусідній файл; збільшити / зменшити; перенести файл у Кошик після підтвердження |
| ← / →; Alt+← / Alt+→ | Відео: перемотати; попереднє / наступне відео |
| F1 | Головне вікно: відкрити/активувати довідку; сама довідка: активувати її |
| Ctrl+F; Alt+← / Alt+→ | Довідка: фокус пошуку; назад / уперед в історії |
| Enter | Пошук довідки: відкрити вибраний результат; кнопка ілюстрації у фокусі: збільшити |
| Esc | Довідка: закрити збільшене зображення; поле пошуку: очистити запит, потім повернути фокус статті |
| Alt+F4 | Закрити активне вікно зі звичайною перевіркою незбереженої роботи |

Ctrl під час перетягування файлів вибирає копіювання; звичайне перетягування — переміщення. Це жест файлового менеджера. Ctrl+N/O/P та Delete/F2 для файлів не призначені як універсальні команди програми: використовуйте видиме меню. Ctrl+C у текстовому полі AI не замінює окрему кнопку копіювання вибраних повідомлень. Обмеження Undo для зображень описані в темі редагування.
