# Editing Markdown source

Markdown is a separate text document containing markup. It can remain open alongside an ordinary document; file commands apply to the selected editor.

## Steps

1. Open a .md file or create a Markdown document. Type markup in the source field. Tab inserts a tab; Ctrl+Z undoes input in this field.
2. Click **Preview** to see the result. **Editor** returns to source. Change the source markup to change the result.
3. The help button opens the syntax article in a separate modeless window. The main editor and both documents stay in place. Close help with its close button or Alt+F4 while it has focus.

![Editing Markdown source — Interface state 1.](images/S17-a.png "Editing Markdown source — Interface state 1.")

## Check, undo and limitations

Use **Save** or Ctrl+S; Ctrl+Shift+S chooses another file. Check source after reopening. Preview is regenerated from the current text and cannot be converted back into Markdown. The ordinary editor's formatting panels do not format Markdown. Switching pages does not save changes; account for unsaved text before closing.
