# The ink palette

**Ink palette** above the document provides quick text colours. Changing a palette slot and applying it to text are separate actions.

## Steps

1. Select text or position the caret for new typing.
2. Click a palette colour to apply it to the text.
3. To replace one slot, right-click it and choose a colour from the set. Then click the slot normally if you want to apply that new colour.

![The ink palette — Interface state 1.](images/S09-c.png "The ink palette — Interface state 1.")

## Check, undo and limitations

Check the letters and the slot tooltip. Choosing a colour in the set updates the palette setting without automatically recolouring the document. Click outside to close the set. Ctrl+Z reverses document edits; select the previous slot colour manually to restore the palette. Palette choices are stored in application settings and do not change the window theme. TXT cannot retain text colours.
