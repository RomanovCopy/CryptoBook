# Keyboard shortcuts and focus

A shortcut works in the stated window or control when its command is available. Click the intended editor, field or list first. Outside an editor, Tab and Shift+Tab move focus; inside an editor, Tab may insert a tab. Space acts on a focused checkbox or button, and Enter follows the current field's rules.

## Documents and protection

| Keys | Scope and action |
| --- | --- |
| Ctrl+S / Ctrl+Shift+S | Ordinary or Markdown editor: save / save as |
| Ctrl+Z / Ctrl+Y | Editable text with focus: undo / redo an available change |
| Ctrl+X / C / V / A | Focused text field: cut / copy / paste / select all |
| Ctrl+B / I / U | Ordinary editor: bold / italic / underline; not Markdown-source formatting |
| Enter / Ctrl+Enter | Ordinary editor: line break / new paragraph; lists retain their own rules |
| Ctrl+F | Ordinary or Markdown document: open search |
| F3 / Shift+F3 | With document search open: next / previous match |
| Enter / Shift+Enter | Document search field: next / previous match |
| Esc | Open document search: close it |
| Ctrl+L | Main window or settings: reset the current key; consider the protected-work snapshot |
| Ctrl+wheel | Ordinary editor: zoom; the 100% button resets it |
| Ctrl+left drag / Esc | Document background: move / cancel the current movement |
| Alt+↑ / Alt+↓ | Selected embedded image: move; structure tree: move a node |
| Delete / Esc | Selected embedded image: delete / deselect |
| Ctrl+Enter | Structure tree: add a paragraph at the selected node |
| ← / PageUp; → / PageDown; Home / End | Ordinary document preview: previous / next / first / last page |

## Other windows

| Keys | Scope and action |
| --- | --- |
| Ctrl+Enter | AI prompt field: send; ordinary Enter inserts a line break |
| Ctrl+M | File manager: batch rename with at least two eligible files selected |
| Alt+Enter | File list: detailed properties of the selected item |
| Enter / Esc | Address field: apply / cancel; while editing a name: confirm / cancel that name |
| Enter | Filename search in settings: search; key dialog: confirm when its requirements are met |
| Esc | Batch rename: close or request cancellation of the running operation |
| ← / →; ↑ / ↓; Delete | Image viewer: adjacent file; zoom in / out; send the file to the Recycle Bin after confirmation |
| ← / →; Alt+← / Alt+→ | Video: seek; previous / next video |
| F1 | Main window: open/activate help; help itself: activate it |
| Ctrl+F; Alt+← / Alt+→ | Help: focus search; back / forward through history |
| Enter | Help search: open selected result; focused illustration button: enlarge |
| Esc | Help: close enlarged image; search field: clear query, then return focus to article |
| Alt+F4 | Close the active window with its usual unsaved-work checks |

Ctrl while dragging files selects copying; an ordinary drag selects moving. This is a file-manager gesture. Ctrl+N/O/P and Delete/F2 for files are not assigned as universal application commands: use the visible menu. Ctrl+C in an AI text field does not replace the separate button for copying selected messages. Image Undo limitations are described in the editing topic.
