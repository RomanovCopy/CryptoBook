# Fonts, text colour and highlighting

The **Font** panel changes selected text. With no selection, settings apply to subsequent typing. Open an ordinary document in editing mode.

## Steps

1. Select a passage and expand **Font** above the document.
2. Choose **Font family**, **Style**, **Weight**, **Decoration**, **Stretch** and **Size**.
3. **Color** changes letters; **Highlight** changes the highlight behind them. Paper colour is separate. Use **_Clear formatting** in the context menu to reset text formatting.

![Fonts, text colour and highlighting — Interface state 1.](images/S08-b.png "Fonts, text colour and highlighting — Interface state 1.")

## Check, undo and limitations

Check the selected passage and use Ctrl+Z to undo an unwanted change. Available families and faces depend on installed fonts. Save as RTF or XamlPackage and reopen a copy to check formatting. TXT and the current XAML handler save text without this formatting. Markdown uses its own source syntax.
