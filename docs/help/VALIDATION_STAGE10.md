## Безопасный объём проверки обновления

Настоящие ApplicationUpdateService, ApplicationUpdateCoordinator и UpdateNotificationViewModel
работали с отдельным учебным источником метаданных, без HTTP. **99.0.0 — вымышленная версия**;
это указано в тексте, подписи и паспорте кадра. Сервис установки заменён запрещающим запуск
приёмником, сама команда установки не вызывалась. Проверены отключение повторного запроса,
интервал, позже/пропуск, ручной обход, ошибки и отмена; старый баннер после ошибки скрывается.

Отдельные тесты используют настоящий загрузчик с синтетическим HTTP-транспортом, временными
файлами, подставным результатом Authenticode и приёмником запуска. Проверены SHA-256,
согласованность адресов выпуска, допустимые/недопустимые состояния подписи, определённый
и неопределённый прогресс. Добавлен тест отмены после получения части данных:
`.download` удаляется, итоговый установщик отсутствует, запуск/проверка подписи не происходят,
прежний установщик и посторонний файл остаются без изменений.

**Не выполнялись** реальные запросы GitHub, загрузка публичного exe, проверка его подписи
Windows, UAC, запуск установщика и обновление рабочей установки/portable. Сохранность
установленного пользовательского профиля после настоящего обновления здесь не заявляется.
Мигратор проверен на вымышленных каталогах, не на профиле пользователя.
Это конкретное ограничение проверки этапа 10; локальная поставка остаётся этапу 12.

## Найденные и исправленные неточности

- В узкой навигации настроек длинные русские подписи обрезались и появлялась горизонтальная
  прокрутка. Горизонтальные StackPanel заменены ограниченными DockPanel с переносом текста;
  горизонтальная прокрутка отключена. Все семь названий измерены на четырёх культурах.
- Первые обрезки S46-b/S47-c/d/e захватывали часть соседнего текста. Они пересняты по границам
  настоящих элементов; текущие кадры показывают полные подписи и кнопки.
- DocumentTemplateDialogTests зависел от порядка запуска и писал в Windows test user.config.
  Добавлен существующий MemorySettingsProvider, проверка Save/Reload читает этот же
  изолированный провайдер. Первый самостоятельный прогон с отказом доступа и промежуточный
  отказ чтения через новый стандартный Settings не считаются успешными. Финальные 5/5 прошли.
- Реестры больше не называют справку будущей, не скрывают help.use и не утверждают, что
  доступны только два образца. После завершения каталога проверка неизвестной цели заменяет
  прежнюю проверку planned settings.data; отдельный MemorySource-тест planned-политики сохранён.
- README en/ru уточняют Windows-профиль portable, установщик при встроенном обновлении,
  папку личных документов, текущую справку разработки и восемь процессов штатного тестового
  скрипта вместо устаревших шести. Это не утверждение нового публичного релиза.
- Описаны немедленное сохранение темы/языка/шаблона, приоритет открываемого файла при запуске,
  различие рабочей папки и профиля, содержимое поискового индекса обычных документов,
  диагностический журнал и отсутствие сохранения чата между запусками.
