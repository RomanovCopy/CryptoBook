# Проверка этапа 3: работающее окно справки

29 октября 2026 года. Ветка `updates`, HEAD `8617d991080b2d3b2b0f920b5a2c7bc741a555a7` с рабочими изменениями этапов 2–3. Версия приложения `1.1.5.2`, SDK `10.0.403`. Публикация и изменение версии не выполнялись.

## Реализованный объём

- Боковое меню → «Справка» и F1 из главного окна, включая вложенный редактор. Отдельное немодальное окно с явным владельцем MainWindow; один экземпляр, активация/восстановление свёрнутого окна, закрытие и повторное открытие.
- Оглавление слева, статья справа, разделитель, поиск текущего языка с задержкой/Enter, пустой запрос/нет результатов, история ID/прокрутки, кнопки/клавиши навигации и увеличение иллюстрации с возвратом. Сохранение темы/геометрии/ширины панели в совместимых пользовательских настройках.
- Смена культуры очищает запрос/выдачу, сохраняет ID темы и историю, обновляет изображения/текст/дерево/подписи. Четыре языка UI, 13 новых ключей на язык; общие ресурсы теперь содержат по 1147 ключей.
- Единственный источник материалов `docs/help/content/` встроен в ресурсы CryptoBook. Две темы × четыре культуры, 28 настоящих PNG. 74 плановые темы скрыты, `doc.save` отображается без активного перехода и с пояснением.
- Markdig/WPF-рендерер получает отдельную ограниченную политику справки. Внутренние адреса и изображения проверяются по каталогу, чужие схемы/пути/percent-encoding не разрешаются, внешние ссылки не запускаются. Обычный Markdown и AI сохраняют прежнюю политику.
- Старая MarkdownSyntaxHelp, её примеры и возврат сохранены; добавлен переход к `start.interface`. Перенос примеров и прямой вход на `md.syntax` остаются этапу 5.

## Воспроизводимая изоляция

Использован [HelpValidation](../../tools/HelpValidation/README.md). Он устанавливает MemorySettingsProvider до создания `App`, затем запускает производственный `App.OnStartup`, XAML, Autofac и команды с явными тестовыми регистрациями. Пользовательская миграция и производственные crash-log handlers не подключаются. Все JSON/index/recovery/lock направлены в новый каталог `artifacts/...`; тема/палитра/геометрия/язык сохраняются только в памяти. IPC/обновления/мониторинг дисков заменены безопасными заглушками, модель не загружается. Выбор папки возвращает только папку демонстрации.

Для этого добавлен внутренний конструктор App с DI-overrides; обычный `App()` сохраняет прежний путь миграции и диагностики. URI словарей App.xaml явно указывают сборку CryptoBook, чтобы тот же UI можно было загрузить из изолированного хоста. `IWindowManager.CreateOwnedWindow` добавлен без изменения владельцев остальных окон.

Проверка ресурсов выполнялась с аргументом корня `artifacts/help-offline-check` и рабочим каталогом нового sandbox, где нет дерева исходников/статей. `HelpContentService` читает только ресурсы сборки; никакой подстановки текстов/PNG из репозитория нет. Сетевые действия справки отсутствуют; updater/activation в хосте отключены. Это проверка ресурсов локальной сборки, а не полной single-file публикации/установщика этапа 12.

## Границы подтверждения и продолжение

Функциональные действия выполнены производственными ICommand/сервисами и маршрутизированными F1/Esc; Tab/Shift+Tab — WPF focus traversal. Физические клавиатура/мышь, реальное переключение Windows-масштабирования/мониторов, установленный пользовательский профиль и миграция не проверялись. 144 DPI — рендер того же WPF-layout, а не изменение настроек экрана пользователя. Эти проверки сохраняются для сводной проверки этапа 11/поставки этапа 12.

Этап 3 закрывает работающий каркас и образцы в указанной изоляции. Полного руководства, single-file/установщика и итоговой регрессии ещё нет. Следующий отдельный объём — этап 4 по [PROGRESS.md](PROGRESS.md).
