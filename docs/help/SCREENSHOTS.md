# План локализованных снимков

Этап 1, 29 октября 2026 года. Основание: UI и обработчики на `933e3b0`, версия `1.1.5.2`. Новые снимки на этом этапе не снимались. Старые изображения не проверены на актуальность и не приняты в справку.

Связи: [оглавление](TOPICS.md), [функции](FEATURES.md), [прогресс](PROGRESS.md).

## Общие параметры паспорта

Каждый ID ниже задаёт сценарий, а не квоту изображений. Суффиксы `-a`, `-b` и далее выделяют необходимые состояния/шаги. Каждый текстовый интерфейс снять отдельно на `en-US`, `ru-RU`, `uk-UA`, `de-DE`; общий исходник допустим только без языковых элементов. Системные диалоги учитывают также язык Windows: несовпадение явно записать, кадр не считать локализованным без решения на тематическом этапе.

Поля, наследуемые каждой строкой:

| Поле | Значение на этапе 1 |
| --- | --- |
| Языки и проверка | `en-US=не снято; ru-RU=не снято; uk-UA=не снято; de-DE=не снято` |
| Состояние/данные/повтор | Указаны в сценарии ниже; точные номера шагов появятся с текстом статьи |
| Дата фактической съёмки/проверки | Не выполнялась; дата плана — 2026-10-29 |
| Исходник | Планируемый редакционный путь `docs/help/screenshots/raw/<culture>/<shot-id>[-state].png`; файлов пока нет |
| Аннотации | Отдельно от raw: план `docs/help/screenshots/annotations/<culture>/<shot-id>[-state].*`; формат выбирается на этапе 2 |
| Подпись/alt | Рабочая русская подпись в таблице; перевод и альтернативный текст обязательны для всех языков при подготовке статьи |
| Поставка | Эти пути не утверждают размещение ресурсов приложения; его выбирает этап 2 |

Размеры указаны в DIP при 96 DPI; фактический паспорт сохраняет и DIP, и пиксели, DPI, тему, культуру, версию, HEAD и способ получения. Базовый кадр должен показывать саму команду читаемо. Дополнительные проверки 144 DPI (150%), узкого окна и четырёх тем выполняются на тематических этапах и сводятся на этапе 11.

Профили: `M` — основное окно 1440×960; `E` — FileExplorer 1280×900; `D` — диалог по содержимому до 1000×960; `P` — правая панель крупным фрагментом в M; `S` — системный диалог по фактическому размеру; `H` — будущее окно по этапу 2. Часть небольших мониторов потребует меньшего окна/крупных фрагментов; не уменьшать целое окно до нечитаемых надписей.

## Демонстрационные данные и безопасность повторения

В последующих этапах создать отдельную рабочую папку демонстрации: обычный документ «План поездки» с абзацами, ссылкой, таблицей 3×3 и вымышленными закладками; Markdown с той же темой; папку `Files` с тремя копиями изображений и текстовыми файлами; отдельные `ConflictSource`/`ConflictTarget`; искусственный двоичный файл. Имена и содержимое примеров локализуются. Для удаления/шифрования/сбоев использовать только отдельные расходные копии. Путь к личной папке, реальное имя пользователя и исходный рабочий стол не должны попадать в кадр.

Для AI — служебный вопрос о вымышленном плане и таблице; модель/vision-проектор выбираются по фактической доступности. Не выдавать подставленный текст ответа за полученный от модели. Пароли/ключи не печатать в материалах и не хранить в паспорте. Снимок с отображённым паролем не нужен.

До съёмки изолировать конфигурацию демонстрационного процесса и проверить все хранилища: обычные `Properties.Settings`, общие AI JSON, палитру, тему, историю/избранное, runtime-профили и recovery/lock. Собственная конфигурация exe не гарантирует изоляцию сервисов с жёстким `%LOCALAPPDATA%/CryptoBook`. Не запускать старую утилиту только ради получения кадров: она пишет в `docs/screenshots`, перезаписывает демонстрационные документы и принудительно завершает процесс. Нужный способ безопасной изоляции ещё предстоит определить; это не поручение изменить утилиту на этапе 1.

## Старые материалы и открытые условия

`docs/screenshots/README.md` описывает восемь кадров версии 1.1.4.7: editor, document-search, side-menu, sepia-reading, markdown-preview, markdown-help, new-document, template-settings; исторический settings-themes не используется в текущих README. Их можно использовать как ориентиры композиции для S02/S04/S08/S11/S17/S27/S46, но сначала сравнить с текущим UI и языком. Русский кадр не закрывает остальные три языка.

Утилита `tools/ScreenshotCapture/Program.cs` прочитана для определения ограничений: только ru-RU, RenderTargetBitmap при 96 DPI, собственный набор демонстраций, без обычного startup. Она не проверяет команды всего приложения, MTP, печать, обновление или фактическую генерацию. На этапе 1 не запускалась.

Для каждого реально снятого файла дописать конкретное состояние, шаг статьи, полный относительный путь raw/аннотации, переведённую подпись/alt, размер/DPI, язык приложения и ОС, способ воспроизведения, дату и результат проверки. Пока все такие поля остаются «не снято», включая Android, cross-device, принтер и модель/vision. Пользователь 2026-10-29 подтвердил перенос зашифрованного файла на Android и расшифрование прямо на месте; это подтверждает сценарий, но не заменяет локализованную съёмку. Это план следующей работы, а не комплект готовых иллюстраций.
