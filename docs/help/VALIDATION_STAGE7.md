## Уточнения по текущему приложению

- Поиск имени и содержимого ограничен локальной рабочей папкой, включая доступные подпапки. Поиск файлов не видит несохранённые изменения редактора. Имя — подстрока без учёта регистра; содержимое — буквальная строка/фраза, до 200 результатов и обычно до 16 МиБ на файл. Markdown ищется как сохранённый исходник. Открытие результата не переводит к совпадению; для этого нужен отдельный поиск документа.
- В обычном документе постраничный просмотр закрывает поиск. Find/Ctrl+F из чтения возвращает в редактор. В Markdown поиск действует по видимому source/preview. Это подтверждено живым WPF, а не прежней общей формулировкой инвентаризации. Enter действует в поле запроса; F3 — в области документа с открытой панелью; Shift-варианты дополнены существующими целевыми тестами. Физические нажатия не заявляются.
- Удаление из **результата поиска** идёт через IFileManagerService → LocalStorageProvider и выполняет прямое удаление после подтверждения, без корзины. Отдельная продуктовая поправка от 31 октября переключила **просмотрщик изображений** на IRecycleBinService: предупреждение и подтверждение, затем перенос исходного файла в корзину Windows; при ошибке файл остаётся на месте. Статья view.images и её поисковые слова исправлены на четырёх языках. Первоначальные capture/verify-отчёты этапа 7 получены до этой поправки и не подтверждают новое поведение корзины медиаплеера.
- ↑/↓ в изображениях меняют **масштаб**, поворот — отдельная кнопка. ←/→ — соседние изображения; края не зациклены. Ошибочное описание поворота стрелками в F098 исправлено.
- Android: provider-wide capabilities отличаются от per-file capabilities; записываемый файл может иметь Encrypt, удалённая папка — нет. Для расшифрования читаемого удалённого файла с ключом отдельный Encrypt не требуется; замена требует Write+Delete. Подтверждение пользователя от 29 октября сохранено отдельно от новой аппаратной приёмки. ANDROID_STORAGE.md исправлен по этим границам. Удалённый preview читает сырой поток и не выполняет автоматическое расшифрование.
- PDF не редактируется внутри CryptoBook; системный диалог печати и внешняя PDF-программа зависят от Windows. Печать проверена на подготовленном содержимом через отдельный sink, а не отправкой задания принтеру.
