## Существенные уточнения

- Одна .bak — предыдущая успешная версия, не полная история. Восстановление открывает её как изменённую без записи поверх исходного файла. При смене ключа несовместимая .bak синхронизируется с текущим защищённым файлом и не обязана содержать более старый текст.
- Аварийный снимок несохранённой работы отделён от lock-снимка. При запуске прежняя аварийная копия откладывается; ручная команда меню Файл позволяет восстановить последнюю отложенную. При запуске уведомления не показываются. Восстановление открывается вручную из меню Файл. Перед удалением использованной копии новая копия возвращённой работы записывается на диск.
- Ctrl+L с одними обычными документами очищает только ключ. Защищённая работа возвращается по команде меню Файл → Восстановить снимок после сброса ключа. При сбое снимка скрытая работа остаётся в памяти, ключ очищается; процесс нужно разблокировать прежним ключом до закрытия.
- На ошибочном кадре после возврата двух редакторов обнаружена пустая Markdown-страница при сохранённых данных обычного документа. Исправлена регистрация неактивных страниц без промежуточной навигации; принятые кадры показывают реальный возвращённый текст.
- Четыре UI-ресурса имеют одинаковые 1125 непустых ключей. Исправлены жёстко заданные строки окон разблокировки/выбора восстановления и интервалов. Независимая языковая вычитка остаётся этапу 11.
- Прежние ограничения Q12 (Undo bitmap) и Q13 (сохранение якорей закладок) не изменены. Поиск содержимого удаляет напрямую; файловый менеджер и плеер изображений используют корзину. Ограничения MTP/видео/печати сохранены в отчётах этапа 7.
