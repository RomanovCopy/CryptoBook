## Изолированная проверка справки

Сначала сохраните свою обычную работу. Следующая команда запускает отдельное окно
с вымышленными файлами, двумя несохранёнными документами и учебным черновиком AI.
Постоянные настройки и хранилища изолированы. Модель не запускается.
Выполните из корня репозитория после сборки HelpValidation:

```powershell
$repoPath = (Get-Location).Path
$stageTmp = Join-Path $repoPath 'artifacts/stage11-manual/tmp'
New-Item -ItemType Directory -Force -Path $stageTmp | Out-Null
$previousTemp = $env:TEMP
$previousTmp = $env:TMP
$previousTag = $env:CRYPTOBOOK_HELP_STAGE11_EVIDENCE_TAG
try {
    $env:TEMP = $stageTmp
    $env:TMP = $stageTmp
    $env:CRYPTOBOOK_HELP_STAGE11_EVIDENCE_TAG = 'manual'
    dotnet 'tools/HelpValidation/bin/Release/net10.0-windows10.0.17763.0/win-x64/HelpValidation.dll' $repoPath ru-RU 'a82f67c+stage11-review' stage11-input
} finally {
    $env:TEMP = $previousTemp
    $env:TMP = $previousTmp
    $env:CRYPTOBOOK_HELP_STAGE11_EVIDENCE_TAG = $previousTag
}
```

Папка учебных файлов выводится после `STAGE11_INPUT_READY`.
Отчёт клавиш — `screenshots/validation/stage11/manual/input-ru-RU.json`,
результат сохранности — `artifacts/hv/ru-RU/<идентификатор>/result.json`.
Повтор с тем же тегом заменяет только данные `manual`; для нового прохода задайте
другой тег из латинских букв, цифр, `-` и `_`. Прежние доказательства этапа 11
и продолжения не перезаписываются.

1. Физической клавиатурой проверьте F1, Tab/Shift+Tab, видимый фокус, стрелки дерева,
   Enter на выбранной теме и иллюстрации. Колесом и полосой прокрутки прочитайте
   длинную статью до конца. Не ограничивайтесь первым экраном.
2. Ctrl+F: найдите слово текущего языка, откройте результат Enter. Введите заведомо
   отсутствующее слово; текущая статья должна остаться. Esc очищает запрос,
   повторный Esc возвращает фокус статье. Кнопка оглавления возвращает дерево.
3. Откройте две темы и проверьте Alt+←/→ и возврат места чтения. Увеличьте картинку:
   Tab/Shift+Tab остаются внутри слоя, Ctrl+F и Alt+←/→ не меняют скрытую справку,
   Esc закрывает картинку и возвращает прежний фокус.
4. Не закрывая справку, смените язык в **Настройках**. Тема должна сохраниться,
   запрос/результаты очиститься, текст и изображение перейти на новый язык.
   Повторите для en-US, ru-RU, uk-UA, de-DE; смена языка не переводит учебные документы.
5. Проверьте Light, Dark, System и Sepia, узкое окно, читаемость длинных таблиц,
   немецких команд и подписей. Закройте справку последней: это завершает стенд
   и проверяет сохранность двух исходных несохранённых документов и черновика AI.

Во время этого сценария не сохраняйте, не заменяйте и не редактируйте учебные
документы: его заключительные проверки требуют исходный текст и dirty-состояние.
Журнал фиксирует события WPF только окна справки. Их происхождение укажите вручную:
**физические нажатия человеком** либо автоматизация. Сам журнал это не различает.

## Настоящий DPI и мониторы

Изменение масштаба Windows выполняет проверяющий; стенд его не меняет.
Запишите исходную конфигурацию и верните её после проверки.

| Проверка | Что наблюдать | Результат |
| --- | --- | --- |
| Windows 150% и 200%, новый запуск окна на каждом масштабе | Оглавление, подписи, кнопки, прокрутка и увеличение остаются доступны; окно помещается в рабочую область | Не выполнено |
| Перенос открытой справки между мониторами с разными DPI | Читаемость, фокус и размеры после переноса в обе стороны | Не выполнено |
| Закрыть справку на втором мониторе, отключить его, снова вызвать F1 | Окно доступно на оставшемся экране; его можно читать и закрыть | Не выполнено |
| Повторить узкий размер на доступных конфигурациях | Нет недоступных кнопок и горизонтального расползания всей статьи | Не выполнено |

`environment-*.json` записывается при открытии окна и не доказывает последующий
перенос или смену DPI. Для каждого состояния приложите наблюдение проверяющего
и обезличенный снимок самого окна. RenderTargetBitmap и LayoutTransform
в прежних отчётах этими проверками не являются.

## Сочетания в остальных областях

Это отдельные сценарии на расходных файлах, **не проверки сохранности стенда выше**.
Нужна отдельная изолированная интерактивная сессия с доступными командами;
`stage11-input` не является полным стендом для них: его выбор назначения/изображения
подменён очередью, модель не настроена, а итог ожидает неизменённые документы.
Не записывайте недоступную команду или искусственный routed event как успешный жест.

| Область | Физические действия и ожидаемый результат | Результат |
| --- | --- | --- |
| Обычный редактор | Ctrl+S/Shift+S, X/C/V/A, B/I/U, Z/Y; Enter — строка, Ctrl+Enter — абзац; Ctrl+F/F3/Shift+F3/Enter/Shift+Enter/Esc; Ctrl+колесо | Не выполнено |
| Markdown | Save/Save as, Tab, Undo/Redo и поиск отдельно в исходнике/просмотре; форматирование обычного редактора не применяется | Не выполнено |
| Изображение/фон/структура | Alt+↑/↓, Delete/Esc; Ctrl+перетаскивание/Esc фона; Ctrl+Enter и Alt+↑/↓ дерева; учесть Q12/Q13 | Не выполнено |
| Предпросмотр | ←/→, PageUp/PageDown, Home/End меняют страницы при фокусе в просмотрщике | Не выполнено |
| AI | Enter добавляет строку, Ctrl+Enter отправляет вопрос при настроенной модели; выделение сообщений и фокус остаются различимы | Не выполнено |
| Файлы | Ctrl+M для двух локальных файлов; Alt+Enter; Enter/Esc в адресе и имени; Esc отменяет групповую операцию | Не выполнено |
| Плеер изображений | ←/→ выбирают соседний файл, ↑/↓ меняют масштаб; Delete открывает подтверждение, выбрать отмену | Не выполнено |
| Видео | ←/→ — перемотка, Alt+←/→ — соседнее видео при фокусе в его области | Не выполнено |
| Ключ | Enter в расходном диалоге; Ctrl+L с учебной защищённой работой и восстановление прежним учебным ключом | Не выполнено |

Полный справочник областей — [горячие клавиши](content/ru-RU/settings.hotkeys.md).
Рабочие пароли, личные файлы и переписку для проверки не использовать.

## Как зафиксировать приёмку

Для каждой строки укажите дату, язык, тему, Windows DPI, число/расположение мониторов,
тип ввода, фактический результат и путь к доказательству. Ошибку запишите отдельно
с шагами воспроизведения. Отсутствующее оборудование оставьте «не выполнено».
Для закрытия этапа нужны фактические результаты либо явное решение пользователя
о допустимых ограничениях; отсутствие ответа таким решением не является.
