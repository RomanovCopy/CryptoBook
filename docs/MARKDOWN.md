# Поддержка Markdown

## Архитектурный контракт

- `.md` обслуживается отдельными `MarkdownFileTemplate` и страницей
  `MarkdownEditor`.
- Единственный источник истины — строка в `IMarkdownDocumentState`.
- В режиме редактирования строка напрямую связана с обычным `TextBox`.
- При каждом переходе в режим просмотра Markdig заново разбирает текущую
  строку, после чего `MarkdownFlowDocumentRenderer` создаёт новый
  `FlowDocument`.
- Просмотр выполняется через `RichTextBox` с `IsReadOnly="True"`.
- Кнопка справки в редакторе открывает отдельную страницу
  `MarkdownSyntaxHelp` с полным перечнем фактически поддерживаемой разметки,
  командами редактора, описанием результата и явным списком ограничений.
  Кнопка возврата и `Esc` возвращают в редактор.
- При возврате в редактор preview удаляется; обратной конвертации из
  `FlowDocument` нет.
- Обычное, защищённое и аварийное сохранение Markdown получает байты только из
  `IMarkdownDocumentState`. Сохранение обычного оформленного `FlowDocument` как
  Markdown намеренно недоступно.

## Независимые документы и навигация

Home и MarkdownEditor могут одновременно содержать разные документы. При
переключении через SideMenu или кнопки Назад/Вперёд в TitleBar сохраняются
содержимое, путь, формат и ревизии каждого документа. Файловые команды относятся
к выбранному редактору. На время сохранения выбранный документ фиксируется.

Открытие файла заменяет только документ соответствующего редактора; запрос
о несохранённых изменениях относится к заменяемому документу. Закрытие документа
показывает оставшийся редактор. Начальный экран Home доступен при запуске без
документов и после закрытия последнего документа. Пустой редактор Markdown
и связанная с ним страница справки удаляются из навигации.

При закрытии программы проверяются оба документа. Аварийный и защищённый снимки
включают скрытый документ вместе с его метаданными и несохранёнными изменениями.

## Поддерживаемая разметка

- ATX- и Setext-заголовки;
- маркированные и нумерованные списки;
- цитаты и горизонтальные разделители;
- жирный текст, курсив и зачёркивание;
- обычные и автоматические ссылки;
- inline code, indented и fenced code blocks с подписью языка;
- pipe/grid tables из расширенного набора Markdig;
- локальные изображения по относительному пути от каталога `.md`.

## Безопасность

- Активными делаются только абсолютные ссылки `http`, `https` и `mailto`.
  Относительные ссылки, `file:`, `javascript:` и прочие схемы не запускаются.
- Удалённые изображения не загружаются. Для локального изображения запрещены
  абсолютные пути и URI; размер файла ограничен 25 МиБ, декодирование — шириной
  1600 пикселей.
- HTML отключён в pipeline Markdig и показывается как инертный текст. Он не
  создаёт WPF-элементы и не исполняется.

## Текст и кодировка

При чтении распознаются BOM UTF-8, UTF-16 LE/BE и UTF-32 LE/BE. Исходные
переводы строк, кодировка и наличие BOM сохраняются при последующей записи.
