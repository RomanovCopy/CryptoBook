# Групповое переименование

В FileExplorer выделите не менее двух локальных файлов и нажмите **Ctrl+M**, кнопку **A→B**
или «Групповое переименование» в контекстном меню. Папки и файлы Android/MTP
в этой операции не поддерживаются. Нумерация следует порядку файлов в списке
FileExplorer, а не порядку их выделения.

Маска имени по умолчанию — `[N]`, расширения — `[E]` (без точки).
Под каждым полем расположены кнопки `[N]`, `[E]`, `[C]`, `[DMY]`, `[HMS]`.
Нажатие вставляет маску на место курсора в соответствующем поле или заменяет
выделенный текст. После вставки можно сразу продолжать ввод с клавиатуры;
предпросмотр обновляется автоматически. Подсказки кнопок объясняют каждую маску.

| Маска | Результат |
| --- | --- |
| `[N]` | Исходное имя без расширения |
| `[E]` | Исходное расширение без точки |
| `[C]` | Счётчик с заданными началом, шагом и разрядностью |
| `[N1-5]` | Символы 1–5 имени |
| `[N3-]` | Имя начиная с третьего символа |
| `[E1-2]` | Первые два символа расширения |
| `[DMY]` | Текущая дата: день, месяц, год (`28102026`) |
| `[HMS]` | Текущее время в 24-часовом формате: часы, минуты, секунды (`153045`) |

Например, маска `Фото_[C]`, начало `1`, шаг `1`, разрядность `3` дадут
`Фото_001.jpg`, `Фото_002.jpg` и т. д. Пустая маска расширения удаляет расширение.
Поиск и замена применяются ко всему полученному имени вместе с расширением,
после них применяется выбранный регистр. В режиме регулярных выражений
используется синтаксис .NET, включая группы `$1`, `$2` в замене.

`[DMY]` и `[HMS]` доступны в обеих масках. Например, `[DMY]_[HMS]_[C]`
даёт `28102026_153045_001.jpg`. Дата и время берутся по локальным часам
компьютера один раз для всего предпросмотра; выполнение использует уже
показанные имена. «Обновить» или изменение параметров обновляет этот момент.

Предпросмотр обновляется при изменении параметров. Проверьте столбцы «Было»,
«Станет» и «Ошибка», затем нажмите «Переименовать». Одинаковые новые имена,
зарезервированные имена Windows и конфликты с существующими файлами или
папками блокируют выполнение. Кнопка «Обновить» повторно проверяет каталог.

Операция поддерживает обмен именами и изменение только регистра.
Файлы сначала получают временные имена в своих каталогах, затем окончательные;
перезапись существующего объекта запрещена на каждом шаге. При ошибке или
отмене выполняется восстановление исходных имён. Если внешняя блокировка или
новый файл мешают восстановлению, окно показывает текущие пути сохранённых файлов.
Принудительное завершение процесса или отключение питания между шагами может
оставить файлы с именами `.cryptobook-rename-*.tmp` в исходных каталогах.

«Откатить переименование» возвращает имена последней успешной операции,
пока окно открыто; откат также проверяет конфликты. Закрытие во время операции
запрашивает отмену и оставляет окно открытым до завершения восстановления.
Путь активного документа, закреплённые и недавние документы обновляются
по фактическому результату. Ошибка сохранения этих ссылок показывается отдельно.

Здесь реализован ограниченный набор масок по образцу
[инструмента Total Commander](https://www.ghisler.com/advanced.htm),
а не полная совместимость всех его шаблонов и плагинов.
