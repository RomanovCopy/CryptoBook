# Скриншоты CryptoBook 1.1.3.5

Обновлено 13 сентября 2026 года. `editor.png`, `side-menu.png`,
`sepia-reading.png`, `markdown-preview.png` и `markdown-help.png` сняты
с текущих WPF-окон CryptoBook, созданных через контейнер приложения.
Используются настоящие XAML-представления, темы, модели представления,
редактор и движок предпросмотра. Изображения интерфейса не ретушировались.

Снимки показывают вымышленный полевой дневник. Текст, таблица и иллюстрация
созданы для демонстрации; личные документы пользователя не используются.
Оригинальная иллюстрация горного озера и светлый фон с контурными линиями
рисуются средствами WPF; их исходная геометрия находится в
`tools/ScreenshotCapture/Program.cs`. Фон установлен через сервис приложения;
в режиме чтения виден весь лист без наложения границ редактора.

## Демонстрационные документы

- [Альпийский маршрут.XamlPackage](demo/Альпийский%20маршрут.XamlPackage) —
  форматированный документ со встроенной иллюстрацией и фоном страницы.
  Демонстрационный файл сериализуется через штатный кодек с ещё редактируемым
  фоном: при первом обычном сохранении программа предложит зафиксировать кадрирование.
- [Полевой дневник.md](demo/Полевой%20дневник.md) — Markdown с заголовками,
  таблицей, цитатой, списком и относительной ссылкой на локальное изображение.
- [mountain-lake.png](demo/mountain-lake.png) — иллюстрация для Markdown;
  оставьте её в одной папке с документом.
- [paper-background.png](demo/paper-background.png) — исходное изображение фона,
  также встроенное в демонстрационный XamlPackage.

## Повторная съёмка

Из корня репозитория, на Windows с .NET SDK проекта:

```powershell
dotnet run --project tools/ScreenshotCapture/ScreenshotCapture.csproj -c Release -- .
```

Утилита перезаписывает только перечисленные демонстрационные документы
и пять снимков. Она отображает окна приложения и сохраняет их через
WPF `RenderTargetBitmap` при 96 DPI: редактор/меню/Sepia — 1440×960,
Markdown/справка — 1120×960. Системный рабочий стол не попадает в кадр.
Обычный запуск `App` с миграцией настроек, обработкой файловых ассоциаций,
мониторингом дисков и восстановлением документов не выполняется.

Эта съёмка проверяет отрисовку представлений из исходников. Проверка запуска
установленной программы и обновления поверх предыдущей версии выполняется
отдельно при подготовке релиза.

`settings-themes.png` сохранён как исторический материал; текущие README
используют пять новых снимков выше.
