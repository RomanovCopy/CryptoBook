# CryptoBook 1.1.3.5

Windows-бинарники не подписаны Authenticode; контрольные суммы предоставляются
в `SHA256SUMS.txt`, статус подписи — в `SIGNING-STATUS.txt`.

## Основные изменения

- Фоновое изображение можно перемещать сочетанием **Ctrl + перетаскивание левой кнопкой мыши**.
  **Esc** отменяет текущее перемещение. Изображение не выходит за границы бумаги и не оставляет пустых краёв.
- Положение фона сохраняется при масштабировании, прокрутке и изменении размеров окна.
  Устранены заливка рабочей области за листом и двойная отрисовка полупрозрачного фона.
- При сохранении в XamlPackage или защищённый текстовый документ программа запрашивает
  подтверждение обрезки. После успешной записи остаются только пиксели выбранной области,
  а фон больше нельзя перемещать; для нового кадрирования нужно выбрать другое изображение.
- Отмена и ошибка сохранения оставляют исходный фон доступным для перемещения.
  Изображение, выбранное во время записи, не заменяется предыдущим фоном.
- В режиме чтения скрывается слой границ редактора. При возвращении к редактированию
  границы листа восстанавливаются.
- README на русском и английском дополнены новыми скриншотами текущих окон:
  дневник с иллюстрацией и фоном, боковое меню, чтение Sepia, Markdown и справка.

## Highlights

- Reposition a background image with **Ctrl + left mouse drag**; **Esc** cancels the current drag.
- Keep the background within the paper and preserve its placement across zoom, scrolling and resizing.
  Translucent backgrounds are no longer painted twice.
- Confirm cropping when saving XamlPackage or protected rich-text documents. Successful saves embed
  only the selected pixels and lock the crop; select another background image to adjust it again.
- Cancelled or failed saves preserve the editable original. A newer background selected during a save is retained.
- Hide editor page borders in reading preview and restore them when returning to the editor.
- Refresh both README galleries with current WPF views and illustrated demonstration content.
