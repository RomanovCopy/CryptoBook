# CryptoBook 1.1.3.3

Windows-бинарники не подписаны Authenticode; контрольные суммы предоставляются
в `SHA256SUMS.txt`, статус подписи — в `SIGNING-STATUS.txt`.

## Основные изменения

- При создании текстового документа можно выбрать формат A2, A3 или A4,
  книжную либо альбомную ориентацию.
- Лист расположен по центру редактора и автоматически масштабируется по
  доступной ширине при изменении размеров окна. Текущий масштаб отображается
  в строке состояния.
- Ширина документа сохраняется в XamlPackage и защищённых текстовых документах,
  учитывается при переключении документов и подготовке режима чтения.
- Команда вставки изображения теперь доступна и в контекстном меню редактора.
- Добавлена встроенная справка Markdown: примеры поддерживаемой разметки,
  ограничения изображений и ссылок, переход обратно к документу.
- Обновлены README на английском и русском языках и скриншоты программы
  с иллюстрированными демонстрационными документами.

Выбор формата задаёт ширину листа непрерывного редактора. Отдельный экспорт
в PDF в этой версии не добавлен.

## Highlights

- A2/A3/A4 and portrait/landscape selection for new rich-text documents.
- Centered sheet, automatic editor scaling on window resize and visible zoom.
- Document width preserved in XamlPackage/protected rich-text saves, session
  switches and reading preview.
- Insert images directly from the editor context menu.
- Built-in Markdown syntax guide with examples and preview restrictions.
- Updated English/Russian READMEs and illustrated application screenshots.
