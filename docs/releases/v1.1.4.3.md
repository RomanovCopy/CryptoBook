# CryptoBook 1.1.4.3

Подробные свойства файлов и исправления шифрования, расшифровки и экспорта на Android/MTP.

## Изменения

- Добавлено окно подробных свойств файла: тип по содержимому, признаки маскировки расширения, метаданные Windows, права доступа, альтернативные потоки, встроенные и каталожные цифровые подписи.
- Окно открывается из контекстного меню или по Alt+Enter. Доступны поиск, копирование отчёта и расчёт SHA-256/SHA-512 с прогрессом и отменой. Для нелокальных объектов показываются доступные сведения провайдера; анализ содержимого и Windows-метаданные требуют локальной копии.
- Исправлены шифрование, расшифровка и создание защищённых копий файлов на Android/MTP, включая операции Windows → Android и Android → Windows.
- Исправлен экспорт расшифрованного содержимого `.cbook` на Android/MTP: сохраняется исходное расширение, доступны поддерживаемые преобразования формата.
- Удалённые операции используют локальную подготовку и проверку передачи. Конфликты имён разрешаются уникальными именами. При явной замене исходный файл удаляется только после успешной передачи и проверки его неизменности.
- Добавлены регрессионные тесты свойств файлов, удалённых операций шифрования и экспорта.
- Версии приложения, установщика и документации синхронизированы с 1.1.4.3.

## Совместимость и поставка

- Windows 10 1809 или новее, x64. Установщик включает .NET Runtime.
- Формат шифрования документов не изменён.
- Подробности свойств файлов: [FILE_DETAILS.md](https://github.com/RomanovCopy/CryptoBook/blob/v1.1.4.3/docs/FILE_DETAILS.md).
- Статус подписи указывается в `SIGNING-STATUS.txt`, контрольные суммы — в `SHA256SUMS.txt`.
