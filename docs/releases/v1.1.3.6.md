# CryptoBook 1.1.3.6

Релиз усиливает защиту паролей и аварийных копий, добавляет ручной сброс ключа в настройках и убирает уведомления о восстановлении.

## Защита данных

- Для нового шифрования нужен пароль длиной 8–128 символов, содержащий не менее шести различных символов без учёта регистра. Отклоняются цифровые, повторяющиеся и некоторые распространённые пароли. Пробелы разрешены.
- Существующие зашифрованные файлы по-прежнему открываются с исходным паролем. Если старый пароль не отвечает новым требованиям, для нового защищённого сохранения потребуется подходящий ключ.
- Аварийные копии защищённых документов шифруются с использованием пароля, Argon2id и AES-256-GCM. Для обычных документов сохраняется защита Windows DPAPI текущего пользователя.
- Пароль в памяти процесса дополнительно защищён средствами Windows; принадлежащие приложению буферы с чувствительными данными очищаются после использования.
- При ошибке создания или проверки снимка несохранённая защищённая работа остаётся за экраном блокировки. Для проверки пароля используется отдельный зашифрованный проверочный блок.
- Старый формат V1 остаётся доступен для чтения, новые записи используют V2. При замене V1-файла больше не создаётся дополнительная V1-копия `.bak`; существующие резервные копии не удаляются.

## Сброс ключа и запуск

- В разделе безопасности настроек появились команда «Сбросить ключ сейчас», состояние ключа и подсказка Ctrl+L. Перезапуск приложения не требуется.
- Сброс ключа сохраняет открытые обычные документы и их несохранённые изменения. Защищённый документ сохраняется в проверенный зашифрованный снимок и закрывается.
- Удалены запрос восстановления при запуске и баннер восстановления в главном окне. Существующие снимки сохраняются; восстановление через удалённый баннер больше не предлагается.
