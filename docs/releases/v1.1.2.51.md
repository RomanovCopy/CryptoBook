# CryptoBook 1.1.2.51

## Важное исправление обновления

Версия 1.1.2.5 могла не запуститься после установки поверх предыдущей версии:
в каталоге программы оставались файлы среды .NET 8, а новый single-file EXE был
собран для .NET 10. Ошибка происходила до открытия интерфейса и до запуска
встроенной проверки обновлений.

Пользователям 1.1.2.5 необходимо один раз вручную скачать и запустить
[установщик 1.1.2.51](https://github.com/RomanovCopy/CryptoBook/releases/tag/v1.1.2.51)
поверх существующей установки. Удалять программу предварительно не требуется.
Документы и пользовательские настройки не удаляются.

Исправленный установщик удаляет только известные устаревшие runtime-файлы и
каталоги, затем устанавливает актуальный single-file CryptoBook.

## Important upgrade fix

Version 1.1.2.5 could fail before startup after an in-place upgrade because
.NET 8 runtime files remained next to the new .NET 10 single-file executable.
Affected installations cannot run the built-in updater. Download and run the
1.1.2.51 installer manually over the existing installation once. Documents and
user settings are preserved.
