# CryptoBook 1.1.3.0

## Основные изменения

- Добавлена полная немецкая локализация приложения и установщика.
- В установщик добавлен украинский язык, уже поддерживаемый приложением.
- Защищённые медиафайлы V2 теперь расшифровываются в аутентифицированный
  seekable-поток без создания открытой временной копии на диске.
- Встроенный обновлятор проверяет SHA-256 и заявленный статус
  Authenticode до запуска скачанного установщика.
- Переносы файлов и каталогов через Android/MTP проверяют состав,
  размер и SHA-256 каждого файла перед удалением исходника.
- Исправлены горячие клавиши навигации и перемотки защищённого видео,
  поведение кнопок у конца ролика и отображение имени защищённого файла.

## Highlights

- Added complete German localization for the application and installer.
- Added Ukrainian language support to the installer, matching the application.
- Protected V2 media is decrypted to an authenticated seekable stream without
  creating a plaintext temporary copy on disk.
- The built-in updater verifies SHA-256 and the declared Authenticode signing
  state before launching a downloaded installer.
- Android/MTP moves verify directory composition plus every file's size and
  SHA-256 checksum before deleting the source.
- Fixed navigation and seeking shortcuts, end-of-video seek behavior, and the
  protected file name shown in the playback bar.

## Проверка / Verification

- 568 Release-тестов пройдены без ошибок.
- Проверка происхождения FFmpeg и Flyleaf WPF smoke-тест пройдены.
- The local installer build completed successfully with version 1.1.3.0.
