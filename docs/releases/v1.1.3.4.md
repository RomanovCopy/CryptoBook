# CryptoBook 1.1.3.4

Windows-бинарники не подписаны Authenticode; контрольные суммы предоставляются
в `SHA256SUMS.txt`, статус подписи — в `SIGNING-STATUS.txt`.

## Основные изменения

- Добавлено масштабирование текстового редактора сочетанием **Ctrl + колесо мыши**.
- Кнопка **100%** рядом с индикатором масштаба возвращает фактический масштаб
  страницы и прокрутку к левому краю. В режиме чтения эта кнопка скрыта.
- Масштабирование меняет только отображение: размеры страницы, шрифтов и
  содержимое сохраняемого документа остаются прежними.
- При увеличении листа доступна горизонтальная прокрутка. Границы листа и
  индикатор масштаба следуют выбранному увеличению.
- При изменении размеров окна и повторной загрузке представления редактора
  сохраняется коэффициент увеличения относительно вписывания по ширине.
  Поэтому отображаемый процент может измениться при изменении ширины окна,
  в том числе после нажатия **100%**.

## Highlights

- Zoom the rich-text editor with **Ctrl + mouse wheel**.
- Reset the actual page scale and horizontal scroll position with the **100%**
  button beside the zoom indicator; the button is hidden in reading preview.
- Preserve document page size, fonts and saved content while zooming.
- Scroll horizontally across an enlarged sheet, with page borders and the zoom
  indicator following the view scale.
- Retain the zoom factor relative to fit-to-width across window resizing and
  editor view reloads. Resizing can change the displayed percentage, including
  after resetting to **100%**.
