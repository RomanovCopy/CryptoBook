# CryptoBook 1.1.3.2

Windows-бинарники не подписаны Authenticode; контрольные суммы предоставляются
в `SHA256SUMS.txt`, статус подписи — в `SIGNING-STATUS.txt`.

## Основные изменения

- Добавлен отдельный редактор Markdown: редактирование исходного текста и
  переключение в режим просмотра. Поддерживаются заголовки, списки, цитаты,
  таблицы, блоки кода и локальные изображения.
- Обычный документ и Markdown можно держать открытыми одновременно и переключаться
  между ними через боковое меню и кнопки «Назад»/«Вперёд» без потери изменений.
- Сохранение Markdown сохраняет исходный текст, кодировку, BOM и переводы строк.
  В защищённый файл также записывается исходная разметка.
- Аварийное восстановление и снимок при блокировке учитывают оба документа,
  включая скрытый редактор и несохранённые изменения.
- Файловые команды работают с соответствующим документом; при закрытии программы
  проверяются несохранённые изменения в обоих редакторах.
- HTML отображается как текст, удалённые изображения не загружаются. Для перехода
  доступны только абсолютные ссылки HTTP, HTTPS и mailto.
- Обновлены сведения о зависимостях и лицензиях для Markdig.

## Highlights

- Dedicated Markdown source editor and rendered preview with headings, lists,
  quotes, tables, code blocks and local images.
- Independent rich-text and Markdown documents with side-menu and Back/Forward
  navigation that preserves unsaved changes.
- Markdown saves retain source text, encoding, BOM and line endings, including
  source-based protected saves.
- Recovery and lock snapshots preserve both documents; shutdown checks both editors.
- Inert HTML, no remote-image loading, and HTTP/HTTPS/mailto link restrictions.
- Updated dependency notices with Markdig and its BSD-2-Clause license.
