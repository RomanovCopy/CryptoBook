# CryptoBook 1.1.4.2

Шаблоны документов, обновлённый диалог создания и исправление автосброса ключа.

## Изменения

- Добавлены встроенные шаблоны: заметки, план проекта, протокол встречи, дневник и отчёт.
- В настройках внешнего вида можно выбрать шаблон по умолчанию; диалог создания позволяет выбрать другой шаблон для конкретного документа.
- Шаблоны учитывают формат, размер страницы A2/A3/A4 и ориентацию. XamlPackage и защищённые документы сохраняют геометрию страницы.
- Исправлен автосброс ключа шифрования при варианте «Никогда»: таймер отключается и не запускается повторно при активности или смене ключа. Ручной сброс остаётся доступен.
- README и семь скриншотов обновлены по текущим WPF-представлениям приложения.
- Добавлены регрессионные тесты шаблонов, диалога, настроек и отключения таймера.

## Совместимость и поставка

- Windows 10 1809 или новее, x64. Установщик включает .NET Runtime.
- Формат шифрования документов не изменён.
- Статус подписи указан в `SIGNING-STATUS.txt`, контрольные суммы — в `SHA256SUMS.txt`.
- Бинарные файлы не подписаны Authenticode; перед запуском проверьте SHA-256 по опубликованному манифесту.
