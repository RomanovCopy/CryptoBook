# Version 1.1.2.5 requires a manual repair update

> **Do not install the 1.1.2.5 package. Use
> [CryptoBook 1.1.2.51](https://github.com/RomanovCopy/CryptoBook/releases/tag/v1.1.2.51).**

При обновлении поверх предыдущей многокомпонентной версии установщик 1.1.2.5
мог оставить DLL среды .NET 8 рядом с новым приложением .NET 10. В результате
CryptoBook завершался до открытия окна и не мог запустить встроенный обновлятор.

Для восстановления вручную скачайте установщик 1.1.2.51 и запустите его поверх
существующей установки. Предварительное удаление приложения не требуется;
документы и пользовательские настройки сохраняются.

The 1.1.2.5 installer could leave .NET 8 DLLs beside the new .NET 10 executable,
causing CryptoBook to exit before its UI and built-in updater could start.
Manually install version 1.1.2.51 over the existing installation to repair it.
