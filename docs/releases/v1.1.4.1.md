# CryptoBook 1.1.4.1

Исправление списка отключённых внешних устройств в файловом проводнике.

## Изменения

- Исправлена нормализация пути диска при отключении: устройство корректно удаляется из списка.
- При открытии проводника список локальных дисков и переносных устройств сверяется с текущим состоянием системы до восстановления последней папки.
- Недоступность транспорта переносных устройств не блокирует доступ к локальным папкам.
- Обновления устройств выполняются последовательно; закрытие проводника безопасно отменяет обновление.
- Добавлены регрессионные тесты обработки отключения, обновления списка и отмены.

## Проверка кандидата

- Locked restore и 690 Release-тестов пройдены без ошибок и пропусков.
- FFmpeg provenance: Verified; Flyleaf WPF template smoke: PASS.
- Локальное обновление поверх 1.1.4.0 завершено с кодом 0; установленный EXE совпадает с собранным по SHA-256.
- После локального обновления пользователь разрешил публикацию кандидата.
- SHA-256 установщика: `57BD7FF2978AF2D7EE6F4038B59EC4BB5EB04197790849A4D8B7F811C4C2320D`.

## Совместимость и поставка

- Windows 10 1809 или новее, x64. Установщик включает .NET Runtime.
- Обновление поверх 1.1.4.0 сохраняет настройки и документы.
- Статус цифровой подписи публикуется в `SIGNING-STATUS.txt`, контрольные суммы — в `SHA256SUMS.txt`.
- Ручная проверка отключения реального USB/MTP-устройства необходима дополнительно к автоматическим тестам.
