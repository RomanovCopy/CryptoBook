# CryptoBook 1.1.3.8

Релиз добавляет безопасное создание защищённых `.cbook`-копий без изменения исходных файлов.

## Защищённые копии

- В панели инструментов и контекстном меню файлового менеджера появилась команда «Создать защищённые копии (.cbook)».
- Можно обработать один или несколько выбранных файлов. Для нескольких файлов выбирается папка назначения, отображается общий прогресс и поддерживается отмена.
- Исходные файлы остаются без изменений, существующие файлы назначения не перезаписываются.
- При совпадении имён создаются уникальные варианты: `документ.cbook`, `документ (2).cbook` и далее.
- Файлы, которые уже имеют заголовок CryptoBook, безопасно пропускаются и учитываются в итоговом отчёте.

## Проверка перед публикацией

- Каждая защищённая копия сначала создаётся во временном файле.
- Перед появлением в папке назначения проверяется сохранённый тип исходного файла.
- При ошибке проверки или отмене незавершённая временная копия удаляется, а исходник сохраняется.
- Логика выбора уникального имени повторяет попытку, если конфликт возник одновременно с публикацией копии.

## Сохранение из редактора

- Если ключ шифрования уже задан, редактор по-прежнему предлагает защитить обычный документ.
- После подтверждения создаётся отдельная `.cbook`-копия; исходный файл и уже существующие защищённые копии не заменяются.
- Диалоги, команды и итоговые сообщения локализованы для английского, русского, немецкого и украинского интерфейсов.

## Совместимость и поставка

- Windows 10 1809 или новее, x64. Установщик включает .NET Runtime.
- Настройки и документы сохраняются при обновлении поверх 1.1.3.7.
- Статус цифровой подписи указан в `SIGNING-STATUS.txt`, контрольные суммы файлов — в `SHA256SUMS.txt`.
