# CryptoBook 1.1.5.3

Релиз от 2 ноября 2026 года. Пользователь проверил установщик и подтвердил публикацию на GitHub.

## Изменения

- Встроенная автономная справка: 76 тем на четырёх языках, иллюстрации, поиск, история и увеличение изображений. Открывается по F1 и из меню «Справка»; справка Markdown ведёт в соответствующую тему.
- Удаление локальных файлов и папок в файловом менеджере и медиаплеере через корзину Windows. Совместимость с прежними журналами сохранена; доступность восстановления учитывает текущую папку.
- Восстановление аварийных копий и снимков после сброса ключа выполняется вручную через меню «Файл». Автоматические уведомления о восстановлении убраны.
- Уточнены переводы, подписи иллюстраций и обработка клавиатуры при увеличенном изображении.
- Согласованы версии приложения, манифеста, установщика, теста версии и документации поставки.

## Проверка

Новая сборка: 1208/1208 Release-тестов в восьми процессах, без пропусков; валидатор справки — 304 статьи, 588 PNG, 0 ошибок. Проверки происхождения FFmpeg и шаблона Flyleaf пройдены. Версии EXE и установщика — 1.1.5.3. Проверка справки из готового EXE вне репозитория: 5240/5240 проверок на четырёх языках, без ошибок привязок WPF; все 897 встроенных файлов справки сверены с исходниками. Полный тестовый прогон выполнен вне песочницы: системные интеграции недоступны в ограниченной среде. Предыдущая проверка справки: [этап 12](../help/VALIDATION_STAGE12.md). Её аппаратные ограничения сохраняются: физический ввод, Windows DPI, Android/MTP и установка поверх личного рабочего профиля автоматическими сценариями не подтверждены.

Приложение и установщик не подписаны Authenticode. Для публикации сохранён тот же проверенный пользователем установщик с контрольной суммой SHA-256.

Полный список: [v1.1.5.2...v1.1.5.3](https://github.com/RomanovCopy/CryptoBook/compare/v1.1.5.2...v1.1.5.3).
