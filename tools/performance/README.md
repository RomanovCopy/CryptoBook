# Воспроизводимые сценарии производительности

Запуск всех сценариев из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
    .\tools\performance\Run-PerformanceScenarios.ps1
```

Можно выбрать один сценарий: `launch`, `catalog`, `search`, `images` или
`encryption`. Результат печатается построчно в JSON и содержит время,
суммарные managed-аллокации и параметры набора данных.

- `launch` — изолированный запуск Release-сборки до `WaitForInputIdle`;
- `catalog` — загрузка и пакетная сортировка каталогов из 1 000 и 10 000 файлов;
- `search` — холодное индексирование и повторный поиск по 1 000 документам;
- `images` — копирование `FlowDocument` с двумя изображениями 2048x2048;
- `encryption` — потоковое шифрование файла размером 100 МиБ.

Сценарии создают данные только во временном каталоге
`%TEMP%\CryptoBook.Performance` и удаляют каталог конкретного запуска после
завершения.
